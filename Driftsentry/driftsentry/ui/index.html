What happens

  • DriftSentry starts the server and asks which tools it offers.
  • Each tool is checked for safety. Anything that looks side-effecting (send, delete, commit) is never probed — only observed.
  • Safe tools are asked the same questions repeatedly, to learn both the usual answer and how much it naturally varies.
  • That becomes the baseline. From then on the server is re-checked on a schedule.
